| [node-modules-and-git/](node-modules-and-git/README.md) | researched | Whether `node_modules` can stay off the Apple share in both directions for the whole `workspaceRoot`, not only the launch repository, and whether git can run on the host while the agent keeps git in the container. For `node_modules`: achievable as hygiene, not a boundary; a VM-disk volume over `node_modules` beside every `package.json` or lockfile from a walk on the Mac's own disk, an `rslave` root bind, and mounts made on demand when the Mac's FSEvents watch sees a new package; a seccomp trap only as a later strict mode. A VM lab confirmed propagation, zero Mac descriptors for mounted files, FSEvents for guest writes, 890 of 900 bad shared-index reads against 0 private, and the hook skipping the walk. research/ holds both documents, the lab notes, today's behaviour and a digest of the synced-workspace attempts. |

| [synced-workspace/](synced-workspace/README.md) | planned (attempt 1), researched (attempt 2) | Keeping the launcher's workspace on the VM's disk instead of sharing it live: Apple's file sharing holds one host file descriptor per file the guest has cached, so a large `workspaceRoot` fills the Mac's open-file table and every program on the host fails with "Too many open files". attempt-1-architecture.md is the plan of attempt 1: a docker volume per root mounted at the root's own path, a two-way Unison mirror with the Mac folder run by a helper built from the proxy helper's parts, one `.git` per repository bound from the share, `mounts.unsynced` names in place of the overlay scan, the lifecycle, the measured way such a mirror deletes the Mac's files and the three rules against it, known limits, the owner's decisions, and a build order with the places it attaches. attempt-1-progress.md holds the measurements, the survey of other projects and the two reviews behind it. Nothing is built, and the numbers on the real root are still to be taken. Attempt 2, in attempt-2-live-share/, researched keeping the share live through a virtio-fs device of pinata's own on macOS 27's custom device API, which holds no Mac descriptor per cached file; no option met all its eight criteria, and the device came closest. Its earlier phase, Mac kernel limits plus a guest governor on Apple's share, is proposed as the fallback for macOS before 27; the README compares the two attempts and lists the owner's open decisions. |
