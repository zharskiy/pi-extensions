# Review: docs, config, packaging

Scope: README.md, PLAN.md, HANDOFF.md, docs/deviations.md, docs/spike.md, docs/design/agent-and-model-selection.md, research/*.md, package.json, package-lock.json (consistency only), tsconfig.json, vitest.config.ts, vitest.live.config.ts, biome.json, .github/workflows/ci.yml, .gitignore, extensions/subagents/scripts/spike.ts, the three extension READMEs (cross-document only), the prompts and shipped agent files; `git ls-files` and `npm pack --dry-run` output.

Line numbers for docs/deviations.md are real file lines (the file has 217 lines; the numbered entries in the brief's leads are at different lines, for example the compat entries are lines 104-106 and the removal is line 174).

### High
- **Package version is 0.1.0 while the docs, plan and git history say release 0.3** `package.json:3`, `extensions/subagents/README.md:7` ("Release 0.3 adds ..."), `PLAN.md:5`, `git log` ("feat: release 0.3 ..."), no git tags. `package-lock.json` agrees with 0.1.0 (root `version` and the dev and peer dependency blocks match `package.json`). Anything published or installed by version reports 0.1.0. Fix: bump to 0.3.0 (lock too), tag releases.
- **`files` ships every test, fixture, snapshot, the spike script and a stray cache dir** `package.json:14-19`. `"extensions"` whole-directory entry makes `npm pack --dry-run` list 134 files, 599 kB unpacked, of which about 45 are `extensions/*/test/**` (including `recorded-session.jsonl`, the `.snap`, `test/live/fixtures/mcp-server.ts`, `test/helpers/live.ts`), plus `extensions/subagents/scripts/spike.ts`. It also ships the git-ignored, untracked `extensions/subagents/node_modules/.vite/vitest/da39a.../results.json` (a vitest cache created by a run from that directory; `files` bypasses `.gitignore`). Nothing in `extensions/*/src` imports from `test/` or `scripts/` (and `core/test` is correctly not listed), so none of this is needed at runtime. Fix: list only what pi loads, for example `["core/adapter", "core/manager", "extensions/*/src", "extensions/*/prompts", "extensions/subagents/agents", "extensions/*/README.md", "README.md"]` and add `"!**/node_modules"`. Leaving READMEs in is fine. Check with `npm pack --dry-run` afterwards.
- **License declared but no LICENSE file** `package.json:6` says `"license": "MIT"`; `git ls-files` has no `LICENSE*`, and the pack list has none. For a package that is meant to be open source (HANDOFF.md "published as open source") the license text must ship. Fix: add `LICENSE`.
